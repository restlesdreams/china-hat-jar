CHINA HAT — Fabric 1.20.1
========================

Это исходный проект клиентского визуального мода China Hat.

Функции:
- ClickGUI открывается клавишей Right Shift.
- Переключатели Watermark, Coordinates, FPS Counter и Array List.
- Смена акцентного цвета по кругу: голубой, красный, мятный, оранжевый,
  фиолетовый, жёлтый и белый.
- Настройки сохраняются в .minecraft/config/china-hat.json.
- Клиентский мод; серверная установка не нужна.

Сборка JAR:
1. Установите JDK 17 или новее и Gradle 8.6.
2. Откройте терминал в папке проекта.
3. Выполните: gradle build
4. Готовый файл появится в build/libs/china-hat-1.0.0.jar

Установка:
1. Установите Fabric Loader для Minecraft 1.20.1.
2. Установите Fabric API для Minecraft 1.20.1.
3. Скопируйте china-hat-1.0.0.jar в .minecraft/mods.
4. Запустите профиль Fabric 1.20.1.
5. Нажмите Right Shift, чтобы открыть GUI.

Примечание: JAR не приложен, поскольку среда подготовки не имеет доступа к
сети для загрузки Gradle и зависимостей Fabric/Minecraft. Этот архив содержит
исходники проекта, а не готовый скомпилированный мод.
